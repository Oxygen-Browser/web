Privacy, in five lines

Short version: this website collects nothing. Long version:

a.
No analytics.

No Plausible, no Google Analytics, no pixels. The only JavaScript rewrites links and the footer year — locally.

b.
No third parties.

No fonts, no CDNs, no embeds. Everything comes from the same origin as this page.

c.
GitHub Pages hosting.

Static files. GitHub may keep standard server logs (see their privacy statement); we never see them.

d.
Downloads live on Releases.

Subject to GitHub's policies. Verify the published hashes.

e.
The browser.

Zero requests without your action (see FAQ). Crash reporter is stock Firefox: asks first.
