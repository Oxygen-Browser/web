01

What changed

Six decisions, all enforced in source — not in a settings page you'll never open.

  1. /01

    No telemetry pipeline

    Glean recorders, legacy ping senders, upload schedulers and their tests are gone from the tree — desktop, network, geolocation and platform collectors included. There is nothing left to "opt out" of.

  2. /02

    No accounts, no Sync

    Firefox Accounts and Sync are excised from the build. Bookmarks, passwords and history stay on your disk; use a dedicated password manager for the rest.

  3. /03

    No silent updates

    Background update checks, staged rollouts and update telemetry are out. When a new release exists, you hear about it — then you install it.

  4. /04

    uBlock Origin ships with it

    Unbiased blocking from first launch, as a regular distribution extension. Remove it in two clicks if you'd rather choose your own.

  5. /05

    Still Firefox underneath

    Gecko, full add-on compatibility, the same web platform. Migration is opening your profile, not relearning a browser.

  6. /06

    Every diff is public

    The whole fork is 10 patch files against a pinned Firefox tag. Skim them over coffee — that's the entire trust model.

04

Asked often

Does Oxygen collect anything at all?

Nothing leaves your machine unless you make it leave: visiting a site, installing an extension, or enabling a feature that inherently needs the network. If you ever catch it phoning home on its own, that's a defect — report it and it'll get the same treatment as the other 257,879 lines.

Why fork instead of using a user.js?

Preferences can be flipped back by updates, and they can't remove code paths — dead upload machinery, keyed histograms, mirrored probes. Deletion is the only setting that can't be toggled.

Will my extensions and profile work?

Yes. It's Firefox under the paint: same profile format, same addons.mozilla.org. uBlock Origin is preinstalled; everything else installs exactly like you're used to.

How do I update?

You don't, automatically. New releases appear on GitHub with a changelog; download and install when you feel like it. Nothing checks, stages, or nags in the background.

What about crash reports?

Deliberately untouched for now: stock Firefox behavior, which asks before sending anything. Ripping it out entirely is on the roadmap — open an issue if you want it prioritized.

Who's behind this, and what's the catch?

One person, no company, no sponsors, no search-revenue deals, no affiliate anything. The catch is the opposite of usual: updates and ports (Linux, macOS) happen when evenings allow. MPL-2.0, like the Firefox it's cut from.
